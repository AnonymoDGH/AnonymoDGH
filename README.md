Construyo herramientas de seguridad, clientes reverse-engineered y bots. Me meto en las tripas de las cosas — el webpack de Discord, el protocolo de Minecraft, las APIs internas de Qwen y Baidu — y las convierto en código limpio y probado.

Python y JavaScript son mi stack. Si tiene un endpoint, un store interno o un paquete NBT, lo encuentro.
